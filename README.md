# HN Replay — demonstração

Este repositório hospeda apenas uma demonstração limitada do **HN Replay**, portal independente de curadoria de vídeos recomendados por leitores do Hacker News. O pacote comercial completo não está neste repositório.

## Publicar grátis no GitHub Pages

1. Abra **Settings → Pages** deste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha **main** e **/docs** e clique em **Save**.
4. Depois da publicação, confira a URL informada pelo GitHub Pages (normalmente `https://helberrrr.github.io/GPT.-Aposentadoria/`).

O exemplo tem cinco vídeos com reprodução via incorporação oficial do YouTube e links de atribuição ao catálogo HackerTube. Os direitos de vídeos, miniaturas e marcas permanecem com os respectivos titulares. Não há afiliação com YouTube, Hacker News ou HackerTube. Não inclui domínio registrado, audiência verificada ou receita.
